# Amazon.com Clone

A front-end clone of Amazon.com (US website), built using HTML and CSS.

## Features
- Amazon-inspired homepage
- Separate sign-in page
- Horizontally scrollable hero section
- Product categories and shopping sections
- Footer
- CSS styling and layout

## Technologies Used
- HTML5
- CSS3
- Flexbox
- Font Awesome

## Pages
* Homepage: An Amazon.com-inspired layout with a navigation bar, search bar, product sections, and footer.

* Sign-in Page: A sign-in interface inspired by Amazon.com's design.
